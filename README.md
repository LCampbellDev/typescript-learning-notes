# TypeScript Learning Notes

A personal TypeScript documentation bank recording notes, reflections, questions, debugging and application in my own projects.

The notes began while I was completing Codecademy's [Learn TypeScript](https://www.codecademy.com/learn/learn-typescript) course. They are written in my own words and will continue to grow as I learn from the TypeScript documentation, other technical sources, development work and discussion

## Purpose

These notes help me to:

- Record my current understanding
- Preserve questions that led to deeper learning or topics to explore later
- Develop and verify my understanding through multiple sources
- Document the TypeScript code and concepts I have applied and debugged in practical work
- Revisit concepts through retrieval and repetition
- Identify features and concepts to apply in future projects

Every module uses the same sections:

- __A. Core course notes__ — foundational concepts and syntax
- __B. Questions and deeper understanding__ — questions, reasoning and current answers
- __C. Verification and further learning__ — documentation and other sources
- __D. Applied learning__ — mini-projects, debugging and reflection
- __E. Personal project connections and later exploration__ — points to consider applying in my first personal TypeScript project, Seed Keeper
- __F. Retrieval prompts__ — questions for active recall to help embed learning

## Recording questions across modules

Questions do not always arise in the module where the expanded answer belongs. When one concept sparks a question about a later topic:

- The originating module records the question and why it arose
- The fuller explanation is recorded in the most relevant module
- The two notes link to each other

## Sources and verification

Primary references include:

- [Codecademy Learn TypeScript](https://www.codecademy.com/learn/learn-typescript)
- [TypeScript documentation](https://www.typescriptlang.org/docs/)

I sometimes use generative AI to respond to questions that arise while learning or to support Socratic-style dialogue. However, I favour official TypeScript documentation and professional dialogue with mentors when deepening my understanding of TypeScript and its relationship to broader software engineering concepts.

The curated notes retain useful questions and my current understanding rather than reproducing complete conversations. Important technical claims can then be checked against documentation and practical behaviour.
